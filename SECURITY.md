# Security Policy

## Supported Versions
We release patches for supported versions of WeatherDashboard. Please ensure you are using the latest version.

| Version | Supported          |
| ------- | ------------------ |
| main    | ✅                 |
| old     | ❌                 |

## Reporting a Vulnerability
If you discover a security issue, please report it responsibly:

- Email: security@weatherdashboard.com
- Do not disclose publicly until it is resolved
- Provide as much detail as possible (steps to reproduce, impact, etc.)

We will review and respond promptly. Thank you for helping keep WeatherDashboard secure.
